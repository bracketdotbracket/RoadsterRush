# Controls

**Every input, with the timing that makes it work.**

The same steering controls work on the ground and in the air. Boost, stunts and party items are separate actions, so you can plan each around the next section of track.

## Keyboard

| Action                |         Input          | How to use it                                                              |
| :-------------------- | :--------------------: | :------------------------------------------------------------------------- |
| **Accelerate**        |     **W** or **↑**     | Hold to drive forward.                                                     |
| **Brake**             |     **S** or **↓**     | Hold to slow the car. Braking does not engage reverse.                     |
| **Steer**             | **A / D** or **← / →** | Turn left or right, including while airborne.                              |
| **Reverse**           |         **R**          | Hold to slow out of forward motion and drive backwards.                    |
| **Thruster jump**     |       **Space**        | Tap on the ground when reserve and cooldown allow.                         |
| **360 barrel roll**   |    **Space again**     | Release after takeoff, then tap again while airborne.                      |
| **Drift**             |    **X + steering**    | Hold X through the slide. Release it to regain grip.                       |
| **Boost**             |       **Shift**        | Tap to spend one stored canister on ten seconds of boost.                  |
| **Power-up**          |         **E**          | Tap to use the item in your inventory.                                     |
| **Recover car**       |         **F**          | Return to the last checkpoint. Adds three seconds to your final race time. |
| **Change camera**     |         **C**          | Switch between chase and hood views.                                       |
| **Motor audio**       |         **M**          | Toggle the motor sound.                                                    |
| **Pause / race menu** |        **Esc**         | Pause local play or open the menu during an online race.                   |

Use the on-screen fullscreen button to enter or leave fullscreen.

## Three sequences to learn

### Jump → release → roll

Tap **Space** to leave the ground. Release the key, then tap **Space** again while you are still in the air. Holding the key is not a second press.

Steering left or right when the roll starts selects its direction. Neutral steering defaults to a right roll. Continue steering while airborne to line up your landing.

### Steer + drift → release → accelerate out

Hold **X** while steering through the corner. Release X as the car points towards the exit. Drift requires forward road speed; it will not engage off road, in reverse, at low speed or in the air.

### Collect → save → activate

Drive through a blue canister, then tap **Shift** when you want the ten-second burst. Release the key once it starts. To use another canister, wait for the current boost to finish and press again.

## Controller

Standard gamepads use the following mappings. Names follow an Xbox-style controller; equivalent button labels vary by device.

| Action                          | Input                                                           |
| :------------------------------ | :-------------------------------------------------------------- |
| **Accelerate / brake**          | **RT / LT**                                                     |
| **Steer, including in the air** | **Left stick**                                                  |
| **Jump**                        | Tap **A**                                                       |
| **360 barrel roll**             | Release A after takeoff, then tap **A** again in the air        |
| **Choose roll direction**       | Hold the left stick in the desired direction as the roll starts |
| **Drift**                       | Hold **LB + left stick**                                        |
| **Boost**                       | Tap **RB**                                                      |
| **Power-up**                    | Tap **B**                                                       |
| **Reverse**                     | Hold **Y**                                                      |
| **Recover car**                 | **View / Select**                                               |

Camera, audio, fullscreen and menu actions remain available through the keyboard or on-screen controls.

## If an action does not trigger

| Action       | Check this first                                                                                                   |
| :----------- | :----------------------------------------------------------------------------------------------------------------- |
| **Jump**     | Are you grounded, out of cooldown and holding at least 24 jump charge?                                             |
| **Roll**     | Did you release and press again in the air? You need 6 charge and can roll once per jump.                          |
| **Boost**    | Do you have a canister? Wait for an active boost or EMP interruption to end, then tap again while driving forward. |
| **Drift**    | Are you on the road, moving forward at speed and steering with X held?                                             |
| **EMP Trap** | Land on the road before attempting to drop it.                                                                     |

> **Online menu behaviour**
>
> Opening the menu does not pause an online race. Other drivers continue racing.
